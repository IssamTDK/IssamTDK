# Install this GitHub profile

1. On GitHub, create a **public** repository named exactly `IssamTDK`.
2. Copy `README.md` to the root of that repository.
3. Copy the `assets` folder to the same repository, preserving this structure:

   ```text
   IssamTDK/
   ├── README.md
   └── assets/
       └── issam-header.svg
   ```

4. Commit and push the files:

   ```bash
   git add README.md assets/issam-header.svg
   git commit -m "Create professional GitHub profile"
   git push
   ```

GitHub will automatically display `README.md` at the top of your profile.

## Recommended next improvement

Once you have two or three polished public repositories, pin them on your profile and add a short **Featured work** section. Avoid adding empty or low-activity statistics cards; strong project evidence will make the profile more credible.
